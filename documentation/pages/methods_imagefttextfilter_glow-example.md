# [AgjGd](/methods/)::[imagefttextfilter](/methods/imagefttextfilter/) Example: Glow

A glow is built up in two passes. The text is drawn first in yellow with a heavy blur, then the same text is drawn again in black directly on top with no blur at all, leaving the blurred copy spilling out around the crisp letters.

# [AgjGd](/methods/)::[imagecolorallocatefromstring](/methods/imagecolorallocatefromstring/) Example: Alternatives

A tour of every string format the method accepts: six-digit and three-digit hex codes, `rgb()` and `rgba()` with either commas or spaces separating the values, an alpha given as a percentage and a CSS color keyword. Each one allocates the exact same green, so all eight rectangles come out identical.

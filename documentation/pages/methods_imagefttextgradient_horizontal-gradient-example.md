# [AgjGd](/methods/)::[imagefttextgradient](/methods/imagefttextgradient/) Example: Horizontal Gradient

Setting the `$horizontalGradient` parameter to `true` turns the gradient on its side, so the orange-to-purple fade travels along the length of the string from left to right instead of running top to bottom within each letter.

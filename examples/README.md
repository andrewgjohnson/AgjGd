# Examples

The examples can be viewed at [AgjGd.org/examples](https://AgjGd.org/examples/).

Each example is grouped into a folder named after the project it came from, and each writes a PNG to standard output. The `.png` beside each `.php` file is that example’s expected output, and you can regenerate any of them by running the example and redirecting it to the file:

```shell
php examples/imagefttextfilter/01-glow.php > examples/imagefttextfilter/01-glow.png
```
